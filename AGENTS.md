# Project Agent Instructions

- Use HeroUI v3 for React UI work. Ignore HeroUI v2 APIs and do not add `HeroUIProvider`.
- Before implementing a HeroUI component, consult `https://heroui.com/react/llms.txt` or the `heroui-react` MCP server configured in `.mcp.json`.
- Component-only reference: `https://heroui.com/react/llms-components.txt`.
- Pattern reference: `https://heroui.com/react/llms-patterns.txt`.
- Use compound component APIs, semantic variants, React Aria `onPress`, and Tailwind CSS v4.
